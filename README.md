# ChinaCheck

ChinaCheck is a China readiness tool for European hospitality operators.

It helps operators assess:
- Chinese traveller demand by location
- operational readiness for Chinese guests
- channel, payment, language, and digital accessibility gaps
- potential revenue upside from becoming more China-ready

## Live Tool

https://rbisschoff.github.io/chinacheck/

## Local Development

This project is a static HTML tool with the main app in `index.html`.

To preview locally, open `index.html` in your browser.
